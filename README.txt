WEBTECH — STATIC GITHUB VERSION

This version is intentionally a single static index.html.
NO npm, React, Vite, Node.js or build step is required.

GITHUB PAGES:
1. Create/open your GitHub repository.
2. Upload index.html to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select your main branch and "/ (root)".
6. Save.

The site uses Google Fonts from the web. The visual effects, animations,
3D-style technology environment, touch/mouse motion and responsive layout
are all contained in index.html.

Replace hello@webtech.co.za and the sample portfolio text with your actual
WebTech details before launch.
